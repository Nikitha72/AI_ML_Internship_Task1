Student Performance Data Analysis Using Python

Project Description

This project analyzes student marks in Maths, Science, and English using Python and data science libraries.

Objectives

- Load and analyze a CSV dataset.
- Identify the number of rows and columns.
- Examine data types and dataset structure.
- Check for missing values and duplicate records.
- Perform basic data cleaning.
- Generate statistical insights.
- Create data visualizations.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

Dataset

The project uses a sample student performance dataset containing student IDs, names, and marks in three subjects.

Data Analysis

The dataset is examined for missing values, duplicate records, and data types. Statistical summaries and subject averages are calculated.

Visualizations

1. Average marks by subject.
2. Distribution of student average marks.
3. Maths marks versus Science marks.

Output Files

- student_performance.csv
- cleaned_student_performance.csv
- Task1_Student_Performance_Analysis.ipynb
- visualization1_average_marks.png
- visualization2_marks_distribution.png
- visualization3_maths_vs_science.png

Conclusion

This project demonstrates the basic data analysis workflow using Python. It uses Pandas for data handling, NumPy for numerical operations, and Matplotlib for visualizing student performance.
